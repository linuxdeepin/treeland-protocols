Deprecated protocols. No longer implemented or their implementation reliability is not guaranteed in new versions of Treeland.

Only the files Treeland still implements are installed (`TREELAND_PROTOCOL_DEPRECATED_XML_FILES`):
`treeland-capture-unstable-v1`, `treeland-ddm-v1`, `treeland-personalization-manager-v1`,
`treeland-dde-shell-v1`, `treeland-wallpaper-color-v1`. The other files are kept here for reference
only; their implementations were removed from Treeland, so they are not installed — clients that
still use them are meant to fail at build time.
